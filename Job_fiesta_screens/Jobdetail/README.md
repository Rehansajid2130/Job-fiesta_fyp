# Jobdetail React App

This is a minimal React app for the JobdetailsPage component.

## Setup

1. Install dependencies:
   ```
   npm install
   ```
2. Start the development server:
   ```
   npm run dev
   ```
3. Open your browser to the local server URL (usually http://localhost:5173).

## Project Structure
- `JobdetailsPage.jsx`: Main component file.
- `main.jsx`: Entry point for React.
- `index.html`: HTML entry point.
- `assets/images/`: Contains SVG assets used by the component.
